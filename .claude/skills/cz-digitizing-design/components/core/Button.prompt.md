Primary action control — gold fill is the single CTA on any view; everything else is navy, outline or ghost.

```jsx
<Button variant="primary" iconAfter="arrow-right">Get a Quote</Button>
<Button variant="outline">Explore Services</Button>
<Button variant="onNavy" size="sm" icon="download">Export</Button>
```

Variants: `primary` (gold), `secondary` (navy), `outline` (gold hairline), `outlineNavy` (grey hairline, admin toolbars), `onNavy` (translucent, for navy grounds), `ghost`. Sizes 32/40/48px. Press state nudges down 1px; hover lightens gold and adds the gold glow.
