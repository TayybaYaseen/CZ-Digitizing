Renders the CZ Digitizing logo lockup from a real brand asset — use it anywhere a mark is needed instead of setting the name in type.

```jsx
<Logo variant="dark" height={44} assetBase="../../assets" />
```

Variants: `light` (on white/light surfaces), `dark` (on navy), `mono` (single-colour print), `primary` (full lockup with the MACHINE EMBROIDERY DESIGN tagline), `mark` (crescent + CZ symbol only, for avatars/favicons), `appicon` (rounded app tile). Set `assetBase` to the relative path of `assets/` from your page.
